The History of Cryptography

Earlier this week, my teacher told a story about a Greek ruler named Histiaeus. He shaved a trusted slave's head, pricked a secret message into the scalp, waited for the hair to grow back, and only then sent him on his way.

When the slave reached Aristagoras, the ruler of Miletus, the instructions were simple: shave his head again and read what was hidden underneath.

I didn't expect a lesson about encryption to make me curious about ancient history, but it did. It also made me wonder about a much bigger question: if people were willing to go to those lengths to send a secret message, what else have humans done to protect information?

That curiosity is what led me to pick up The Code Book by Simon Singh.

Cryptography In Plain Terms

So... what even is cryptography?

At its core, cryptography is how we protect information by transforming it, so only the right person can understand it. You start with plaintext (normal text) and turn it into ciphertext (encrypted text).

Historically, most ciphers are built from two basic techniques:

Substitution

Replacing symbols with other symbols.

That can be as simple as shifting letters (like the Caesar cipher), or as complex as swapping whole chunks of text using a rule only the sender and receiver know.

Transposition

Keeping the same symbols, but changing their order.

The letters don't change, but the message becomes unreadable because the structure is scrambled.

Many real ciphers mix both ideas because patterns are the enemy. Once codebreakers learn what to look for, a cipher can go from mysterious to obvious surprisingly fast.

The shaved-head story is different—that isn't cryptography, it's steganography: hiding the existence of a message in the first place. The goal isn't to make the message unreadable, but to make it unnoticed.

And that's what makes the history of secret communication so fascinating: humans have always mixed creativity, psychology and technology to outsmart whoever might be watching.

Stories From the History of Secrecy

Steganography didn't stop with shaved heads. In The Code Book, Singh mentions several creative ways people tried to hide messages.

One example comes from ancient China: a message written on a tiny piece of silk, rolled into a small ball, sealed in wax, and swallowed by a messenger to pass guards unnoticed.

Another method involved writing directly onto the wooden base of a wax tablet before covering it with fresh wax. To anyone else, the tablet looked completely blank until the recipient knew to scrape the wax away.

But hiding a message only works until people start searching. After that, the focus shifted from hiding messages to encrypting them.

Simple substitution ciphers, such as the Caesar cipher, were easy to use but also vulnerable. Once codebreakers learned to analyse patterns in language, many supposedly secret messages were no longer secret.

This eventually led to more advanced systems like the Vigenère cipher. Instead of using one alphabet shift, it used many, making it appear unbreakable for centuries... until someone finally figured it out.

Machines Change Everything: Enigma

During World War II, Nazi Germany relied on the Enigma machine to encrypt military communications. Enigma transformed cryptography from something done with pencil and paper into something that could operate continuously on a massive scale.

Instead of using one fixed substitution, Enigma relied on rotating rotors that constantly changed the substitution while you typed. This meant the same letter could encrypt differently every time, making simple pattern analysis much more difficult.

But one of Singh's biggest lessons is that "hard to break" doesn't mean "unbreakable."

Enigma wasn't defeated by one brilliant discovery. It was broken through a combination of mathematics, engineering, captured intelligence and human mistakes. When thousands of messages are sent every day, predictable habits become weaknesses.

Interesting fact

The Enigma machine had an enormous number of possible settings, but human habits, not just mathematics, played a major role in its eventual defeat.

The Math Era: Sharing Secrets Without Meeting

After World War II, cryptography gradually shifted from mechanical machines to mathematics.

One of the most revolutionary ideas introduced in the book is public-key cryptography.

The concept sounds strange at first: you can publish one key for everyone to use while keeping another key completely private. The public key locks the information, but only the private key can unlock it.

This solved one of cryptography's biggest problems: securely communicating with someone you've never met before.

This principle became the foundation of systems like RSA and later PGP, bringing strong encryption from governments and militaries to ordinary people.

Where We Are Now (And What's Next)

Today, encryption is everywhere. Every time you log in, pay online or send a private message, cryptography is quietly working behind the scenes.

Modern systems usually combine multiple approaches. Public-key cryptography establishes trust and securely exchanges keys, while fast symmetric encryption protects the actual data.

Singh also looks toward the future. If large-scale quantum computers become practical, they could threaten some of today's public-key algorithms. That's why researchers are already developing and standardising post-quantum cryptography.

Final Thoughts

If you enjoy clever historical stories and want to understand the ideas behind encryption in a way that's both approachable and memorable, I highly recommend The Code Book.

Oh, and if you want a quick feel for what a cipher actually does, try the examples below. The code demonstrates how the text "HELLO WORLD" can be encrypted using three famous historical ciphers. 


import string

def caesar_cipher(plaintext, shift):
    alphabet = string.ascii_uppercase
    ciphertext = ""
    for char in plaintext:
        if char in alphabet:
            index = (alphabet.index(char) + shift) % 26
            ciphertext += alphabet[index]
        else:
            ciphertext += char
    return ciphertext

def vigenere_cipher(plaintext, key):
    alphabet = string.ascii_uppercase
    key = key.upper()
    key_len = len(key)
    key_pos = 0
    ciphertext = ""
    for char in plaintext:
        if char in alphabet:
            shift = alphabet.index(key[key_pos]) % 26
            index = (alphabet.index(char) + shift) % 26
            ciphertext += alphabet[index]
            key_pos = (key_pos + 1) % key_len
        else:
            ciphertext += char
    return ciphertext

def playfair_cipher(plaintext, key):
    alphabet = string.ascii_uppercase.replace("J", "")
    key = key.upper().replace("J", "I")
    grid = ""
    for char in key + alphabet:
        if char not in grid:
            grid += char
    
    ciphertext = ""
    plaintext = plaintext.upper().replace(" ", "").replace("J", "I")
    
    # Prepare plaintext in pairs
    i = 0
    prepared_text = ""
    while i < len(plaintext):
        a = plaintext[i]
        b = plaintext[i+1] if (i+1) < len(plaintext) else 'X'
        if a == b:
            prepared_text += a + 'X'
            i += 1
        else:
            prepared_text += a + b
            i += 2
    if len(prepared_text) % 2 != 0:
        prepared_text += 'X'

    for i in range(0, len(prepared_text), 2):
        char1, char2 = prepared_text[i], prepared_text[i+1]
        row1, col1 = divmod(grid.index(char1), 5)
        row2, col2 = divmod(grid.index(char2), 5)
        
        if row1 == row2:
            ciphertext += grid[row1 * 5 + (col1 + 1) % 5]
            ciphertext += grid[row2 * 5 + (col2 + 1) % 5]
        elif col1 == col2:
            ciphertext += grid[((row1 + 1) % 5) * 5 + col1]
            ciphertext += grid[((row2 + 1) % 5) * 5 + col2]
        else:
            ciphertext += grid[row1 * 5 + col2]
            ciphertext += grid[row2 * 5 + col1]
    return ciphertext

# Example usage:
plaintext = "HELLO WORLD"
shift = 3
key = "CRYPTO"
playfair_key = "KEYWORD"

print("Caesar ciphertext:", caesar_cipher(plaintext, shift))
print("Vigenere ciphertext:", vigenere_cipher(plaintext, key))
print("Playfair ciphertext:", playfair_cipher(plaintext, playfair_key))
